# Agri Rent - Execution Requirements

To execute this project locally, follow these steps:

## Prerequisites
- **Node.js**: Version 18.0.0 or higher.
- **npm**: Usually comes with Node.js.

## Setup Instructions

1. **Clone the repository** (if you haven't already).
2. **Navigate to the frontend directory**:
   ```bash
   cd frontend
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Run the development server**:
   ```bash
   npm run dev
   ```
5. **Access the application**:
   - Open your browser and go to [http://localhost:5173](http://localhost:5173).
   - The "Account" page is now accessible via the navigation bar.

## Project Structure
- `src/pages/Account.jsx`: The dashboard for user orders and spending.
- `src/App.jsx`: Main entry point for routing.
- `src/components/Navbar.jsx`: Navigation menu integration.
